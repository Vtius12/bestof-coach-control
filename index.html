SPAIN TEAM · Acceso local privado · V1.9.1

Rutina operativa privada

Esta aplicación pública no contiene las fórmulas ni las operaciones del equipo. Importa el archivo HTML de Isaac desde tu iPad; se guardará únicamente en el almacenamiento local de esta instalación.

Comprobando almacenamiento…

El archivo HTML importado no se envía a GitHub. La rutina y los registros quedan en este iPad y en el origen web de GitHub Pages. Para conservar el histórico, exporta copias JSON desde la propia rutina después de cada entrenamiento.

Antes de usar en competición, revisa el contenido técnico de la V1.8 contra el PDF V3. Esta versión valida el acceso offline, pero no certifica todavía la exactitud de todas las operaciones.

Verificando caché offline…

En iPad: en la vista de impresión, abre la previsualización y usa Compartir → Guardar en Archivos.
